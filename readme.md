# Hedera SDK for C#
## Overview
This repo is the .NET implementation of the Hedera Hashgraph SDK, ported from the official Java SDK located at [hiero-ledger/hiero-sdk-java](https://github.com/hiero-ledger/hiero-sdk-java)

The goal of this project is strict behavioral and API parity with the Java SDK, while following idiomatic .NET practices.
